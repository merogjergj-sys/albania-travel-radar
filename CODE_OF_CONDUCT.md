# Code of conduct

We want Albania Travel Radar to be a practical and welcoming open-source
project.

Contributors and maintainers are expected to:

- discuss ideas and code with respect;
- critique the work, not the person;
- welcome beginners and explain unfamiliar terms;
- protect people's privacy;
- reject harassment, discrimination, threats, and sexualised conduct;
- avoid using the project to spam, deceive, or surveil people.

Maintainers may edit or remove contributions and comments that violate these
expectations. Serious or repeated violations may result in a temporary or
permanent ban from project spaces.

Report conduct concerns privately through the contact method on the
maintainer's GitHub profile. Reports will be reviewed as promptly and
confidentially as practical.
